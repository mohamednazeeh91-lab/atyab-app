# تطبيق أطياب الفخامة - POS & ERP (الإصدار المحدث مع خانة الخصم)

هذا المشروع هو النظام المتكامل لإدارة محلات "أطياب الفخامة" (المخزون بـ 14 خانة، نقطة البيع POS مع خانة الخصم، المشتريات والمصروفات، والتقارير المالية والمقارنات).

## كيفية بناء ملف الـ APK:
1. قم بفك ضغط هذا المجلد على جهازك.
2. استخدم Flutter SDK لكتابة:
   ```bash
   flutter pub get
   flutter build apk --release
   ```
